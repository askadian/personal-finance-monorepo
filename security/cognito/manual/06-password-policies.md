# Password Policies Configuration

Guide for configuring password policies and security settings.

## 📋 Overview

Configure password requirements and security policies for your User Pool.

**Estimated Time**: 5 minutes

## Password Policy Settings

**Minimum length:** 8 characters (recommended)

**Character requirements:**
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

**Temporary password validity:** 7 days

**Password expiration:** Optional (not typically used for consumer apps)

## Account Recovery

**Methods:**
- Email verification (recommended)
- SMS (optional)

**Self-service account recovery:** Enabled

## Additional Security

- Prevent user existence errors: Enabled
- Account lockout after failed attempts: Configurable
- CAPTCHA: Available with Advanced Security
