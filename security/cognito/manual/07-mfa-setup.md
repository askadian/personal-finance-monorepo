# Multi-Factor Authentication (MFA) Setup

Guide for configuring MFA for enhanced security.

## 📋 Overview

Multi-factor authentication adds an extra layer of security to user accounts.

**Estimated Time**: 10 minutes

## MFA Options

**TOTP (Time-based One-Time Password):**
- Authenticator apps (Google Authenticator, Authy, etc.)
- Recommended for most users
- No additional cost

**SMS:**
- Text message verification codes
- Backup option
- Incurs SMS charges

## Configuration

**MFA enforcement:**
- Optional MFA (recommended - users can enable)
- Required MFA (for high-security applications)
- No MFA

**Recommended setting:** Optional MFA with TOTP

## User Experience

Users can enable MFA in their account settings:
1. Scan QR code with authenticator app
2. Enter verification code
3. MFA enabled for all future logins
